# Emulator debug surfaces — plan

Spec: `docs/superpowers/specs/2026-08-25-emu-debug-design.md`.
Branches: zed `emu-debug` (off `ggo`), ggo `emu-snapshot` (off `main`).

## Phase A — core read API (`../ggo/tools/ggo-emu-core`)
What: `PpuSnapshot` + `Ppu::snapshot_into` + palette-aware tile decode +
decoded `MapCell`/`OamEntry`; move `savefile.rs` into the core.
Why: the PPU is private and the UI thread never sees it; a copy is the
only honest view, and saves need core-level flush.
1. `ppu.rs`: `PpuSnapshot`, `snapshot_into`, `tile_rgba`, `map_cell`, `oam_entry`. Tests.
2. `savefile.rs` → core, `ggo-emu` re-exports; tests move with it.
3. Commit + push `emu-snapshot`; merge to `main`.

## Phase B — pause / step / snapshot in the drive loop (zed)

5. Transport buttons + `ctrl-alt-p` / `ctrl-alt-.`; readout `paused`. Tests.
6. Commit.
